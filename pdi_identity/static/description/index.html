Escaneo de identificaciones (PDI)

Crea contactos y empleados a partir de la foto de una INE, sin teclear

Cómo funciona

  1. Pulsa Crear desde INE en la lista de contactos o de empleados.
  2. Sube la foto del frente y, si quieres, del reverso.
  3. Revisa y corrige los datos leídos.
  4. Guarda: el registro queda creado.

Qué lee

  • Nombre y apellidos
  • Domicilio
  • CURP, validada con su dígito verificador
  • Fecha de nacimiento y sexo
  • Clave de elector y vigencia

Funciona con

  • Contactos (clientes y proveedores)
  • Empleados

Tus datos se quedan en tu servidor

El OCR corre dentro de Odoo con Tesseract. Las imágenes no se envían a servicios externos y no se conservan, salvo que lo actives.

Requiere Tesseract OCR con el idioma español instalado en el servidor y los paquetes de Python pytesseract y Pillow.
